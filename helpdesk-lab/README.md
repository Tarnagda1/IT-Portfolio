# 🎫 IT Support & Ticketing Lab — ServiceNow

## 🎯 Objective

The goal of this lab was to practice using ServiceNow as an IT support ticketing system. I worked with incident tickets, documented troubleshooting steps, updated ticket information, and followed the ticket from creation to resolution.

---

## 🧱 Lab Environment

| Component | Details |
| ---------- | ------- |
| Ticketing Platform | ServiceNow |
| Ticket Type | Incident |
| Support Area | IT Help Desk |
| Environment | ServiceNow Training / Lab Instance |

---

## ⚙️ Ticketing Process

### 1. Create an Incident Ticket

* Created an incident for a user-reported IT issue
* Added a short description and details about the problem
* Selected the appropriate category and subcategory
* Set the impact and urgency of the incident

![Incident Created](screenshots/incident-created.png)

---

### 2. Assign and Prioritize the Ticket

* Reviewed the incident information
* Checked the priority based on impact and urgency
* Assigned the ticket to the appropriate support group or technician
* Updated the ticket status as work started

![Ticket Assignment](screenshots/ticket-assignment.png)

---

### 3. Troubleshoot the Issue

* Reviewed the information provided by the user
* Identified possible causes of the problem
* Performed troubleshooting based on the reported issue
* Added work notes to document the steps taken

![Troubleshooting Notes](screenshots/troubleshooting-notes.png)

---

### 4. Resolve the Incident

* Confirmed that the reported issue was resolved
* Added resolution notes explaining the fix
* Updated the incident status to Resolved
* Documented the final result for future reference

![Ticket Resolved](screenshots/ticket-resolved.png)

---

## 🔍 Testing & Validation

To verify the ticketing process, I checked that:

* The incident contained the correct user and issue information
* The priority matched the impact and urgency
* The ticket was assigned correctly
* Troubleshooting steps were documented in the work notes
* Resolution information was recorded before closing the incident
